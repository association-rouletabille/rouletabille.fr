rouletabille.fr — Palette Showcase

A curated exploration of colour identities for the static site. Ninety-nine palettes across sixteen themed sections mirror the live navigation, content, card, and footer using the same nine design tokens. Use the filter chips below to browse by nav / content mode.

How to read the showcase

1. Navigation zone

Uses nav background, text, and dim subtitle colors; hover arrows appear in accent.

2. Content zone

Uses content background, body text, links, and accent headings from the main page.

3. Card block

The surface block reveals how content-surface behaves against the main background.

4. Token roles

The ten swatches map to nav-bg, nav-fg, nav-dim, content-bg, content-fg, accent, accent-secondary, content-surface, page-bg, and bright.
