rouletabille.fr — Palette Showcase

Twenty self-contained palette concepts for the static site. Each card mirrors the live navigation, content, card, and footer styling using the same nine design tokens.

How to read the showcase

1. Navigation zone

Uses nav background, text, and dim subtitle colors; hover arrows appear in accent.

2. Content zone

Uses content background, body text, links, and accent headings from the main page.

3. Card block

The surface block reveals how content-surface behaves against the main background.

4. Token roles

The nine swatches map to nav-bg, nav-fg, nav-dim, content-bg, content-fg, accent, content-surface, page-bg, and bright.
